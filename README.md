# utateruno-unofficial-2026
非公式UTAUオンリーイベント「UTAって創る君の声」のサークルをまとめた非公式ファンサイトです。


Googleスプレッドシートを編集するだけで内容が更新される、GitHub Pages 用の静的サイトです。

## 仕組み
- サイト（HTML/JS）は GitHub Pages に置く。基本的に一度置いたら触らなくてOK
- データは Googleスプレッドシートを「ウェブに公開（CSV）」して、ページを開くたびに読み込む
- スプレッドシートを編集 → 数分後（Google側のキャッシュ、最大5分程度）にサイトに反映

## 1. スプレッドシートを用意する
シートを2枚作ります。1行目はヘッダーで、列名は下の表記に**そろえてください**（列の順番は自由）。

### シート「サークル」
| 列名 | 内容 |
|---|---|
| サークルカット | 画像URL、または `cuts/` フォルダに置いたファイル名（例 `A-01.png`） |
| スペース | `A-01`、`A1`、`A-07,08` などの形式。全角や表記ゆれも自動で直します |
| サークル名 / サークルURL / 代表者名 | |
| Twitter | `@id`、`id`、URL のどれでもOK |
| Pixiv / その他1 / その他2 | URL |
| 電子決済 | 「可」「PayPay」など。空欄・「不可」・「なし」は “なし” 扱い |
| お品書き / 告知 | URL |
| R-18 | 空欄なら無し。「有」「○」などが入っていれば有り |
| 頒布物 / 種別 / 新/既 / 価格 / 見本等 / 備考 | 頒布物1件につき1行 |
| 更新日時 | `2026-11-20` のような形式が並べ替えやすくておすすめ |

**頒布物が複数あるとき**は、スクショのシートと同じように、2行目以降のサークル情報を空欄にして頒布物の列だけ埋めてください。
「スペース」か「サークル名」が入っている行から、新しいサークルとして扱われます。

### シート「配置」
| 列名 | 内容 |
|---|---|
| スペース | `A-01` など。空欄にすると「入口」などの目印になります |
| x, y | 左上の位置（マス単位。小数もOK） |
| 幅, 高さ | 大きさ（省略すると1） |
| ラベル | 表示する文字（スペースの場合は省略可） |
| 文字サイズ | ラベルの文字の大きさ（マス1個＝1。省略時0.6） |
| 色 | 目印の背景色（`#f8d9e8` など）。`枠` で会場の外枠、`none` で透明。スペースは空欄なら `config.js` の `rowColors` の色 |

今回の会場の配置は `data/layout.csv` に入力済みです（スプレッドシートで管理しなくてもOK）。

例は `data/circles.csv` と `data/layout.csv` にあります。スプレッドシートの「ファイル → インポート」で取り込めます。

## 2. CSVとして公開する
1. スプレッドシートで「ファイル → 共有 → ウェブに公開」
2. 「サークル」シート・「カンマ区切り形式 (.csv)」を選んで公開し、URLをコピー
3. 「配置」シートも同じように公開
4. 2つのURLを `config.js` の `circlesCsvUrl` と `layoutCsvUrl` に貼る

※公開されるのは選んだシートの値だけです。メモ用のシートは公開しないでください。

## 3. GitHub Pages で公開する
1. GitHub で新しいリポジトリを作り、このフォルダの中身を全部アップロード
2. リポジトリの Settings → Pages → Branch を `main` / `/(root)` にして Save
3. 数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` で見られます

## その他
- 特定のサークルを直接開くリンク：`…/#A-01`
- サークルカット画像は GitHub の `cuts/` フォルダに、Web 画面から「Add file → Upload files」で追加できます（Googleドライブの画像リンクは表示されないことが多いので非推奨）
- ローカルで確認：このフォルダで `python3 -m http.server` を実行して http://localhost:8000 を開く
